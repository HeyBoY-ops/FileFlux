Welcome to FileFlux — an in-memory Unix filesystem emulator.
Supported commands: mkdir <name>, cd <path>, ls [path], pwd, clear, help
Wildcard: cd * navigates to the lexicographically smallest subdirectory.

About Wildcard
cd * navigates to the lexicographically smallest subdirectory in the current directory. If no subdirectories exist, it stays in the current directory.
